Advanced OpenPGP Core
Lifecycle, deep validation, strict policy and session-key inspection.
PasevSU Advanced OpenPGP Core
This module maintains a long-lived OpenPGP identity, validates every component and exposes expert session-key inspection without weakening normal operations.
Security Policy Engine

Creates a local per-operation OpenPGP.js policy. It does not change the global library configuration.

Unauthenticated-message and unauthenticated-stream modes are hard-disabled in Strict Policy. They are not exposed as normal switches.

Deep Key Health & Historical Validation

Cryptographically verifies the primary key, every User ID self-certification and every subkey binding. An optional historical date answers whether the structure was valid at that time rather than only today.

Identity Lifecycle Manager

Extends one existing primary identity instead of creating a new fingerprint. Add role-specific subkeys, revoke one compromised subkey, revoke an obsolete email/User ID, or revoke the complete identity.

Session Key & Recipient Inspector

Parses an encrypted OpenPGP message, lists recipient/signing Key IDs and decrypts only the symmetric session-key packet with the selected private key. Raw session-key bytes stay hidden unless explicitly requested.

ASCII Armor & Message Inspector

Dearmors an OpenPGP block, verifies its armor checksum when present, hashes the binary packet block and extracts recipient/signing Key IDs when the content is an OpenPGP message.
